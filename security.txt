# Architecture Note:
# Fundstash is a 100% on-device, offline personal finance app.
# All data (transactions, budgets, accounts, receipts) is stored locally in an encrypted SQLite database on the user's handset.
# There are no user accounts, cloud databases, or backend servers handling financial records.
