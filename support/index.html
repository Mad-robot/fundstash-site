Support

Write to support@fundstash.app. If an SMS was read wrongly, paste the message with the account numbers masked. Fundstash never sends us your data, so we can only see what you choose to share.

Bank SMS on iPhone

iPhone apps cannot read messages, so a Shortcuts automation hands each text to Fundstash. On iOS 27, open the ready-made automation on your iPhone and tap “Add Shortcut”. Then open it and check that Automation is on and Confirm Before Run is off.

To build it by hand:

  1. Shortcuts → Library → Automation → +. If “Describe a shortcut” appears, tap Edit. Choose Message.
  2. Tap the blue word “Sender”, change it to Message, choose contains and type a single space.
  3. Tap the arrow next to “where” and turn off Confirm Before Run.
  4. Add the action Import bank SMS (Fundstash). Set Message text to Message → Content and Sender to Message → Sender.

iOS shows a small banner when an automation runs. To hide it: Settings → Notifications → Shortcuts → turn off Allow Notifications (or use Screen Time → See All App & Website Activity → Notifications → Shortcuts).

Bank SMS on Android

Allow SMS access when asked, or in Settings → Apps → Fundstash → Permissions. Turn on Auto-Sync in Fundstash Settings. Only completed debits and credits are recorded; offers, recharge reminders, OTPs and failed payments are skipped.

An entry looks wrong

Open it: the original message is shown under the form. Fix the amount, payee or category and save; your edit is final. If on-device AI is on, new entries show a small spinner while the AI double-checks them. Messages it decided were not payments are listed in Settings → Dismissed by AI, where you can restore them.

Backups and moving to a new phone

Settings → Export full backup creates a password-encrypted file with everything, including your settings. On the new phone, install Fundstash, then Settings → Import and pick the file. Keep the password: without it nobody can open the backup.

On-device AI

Phones with Apple Intelligence or Gemini Nano use it automatically. Others can download a small open model (about 400 MB) in Settings → On-device AI. It runs offline once downloaded and can be removed at any time.

Widgets

Long-press your home screen (or Lock Screen on iPhone), tap +, search for Fundstash and add “Spending”. Amounts are hidden while Discreet mode is on.
